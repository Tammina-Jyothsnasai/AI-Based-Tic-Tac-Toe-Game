# AI-Based Tic Tac Toe Game

## Overview

AI-Based Tic Tac Toe Game is an interactive web application that allows users to play Tic Tac Toe against an intelligent AI opponent. The game utilizes Artificial Intelligence algorithms to make strategic moves, providing a challenging and engaging gaming experience.

## Features

* Human vs AI Gameplay
* Intelligent AI Opponent
* Interactive Streamlit Interface
* Real-Time Move Validation
* Winner and Draw Detection
* Responsive Game Board
* Attractive UI Design
* Sound Effects and Background Images

## Technologies Used

* Python
* Streamlit
* Artificial Intelligence
* NumPy

## How It Works

1. The player selects a position on the board.
2. The AI analyzes the current game state.
3. The AI chooses the optimal move.
4. The game continues until a player wins or the match ends in a draw.
